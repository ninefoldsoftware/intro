# ninefold.github.io

Homepage for **Ninefold** — a Kolkata-based web & software studio.

## Repo layout

| Path | What it is |
| --- | --- |
| `index.html` | Homepage |
| `css/style.css` | Site stylesheet |
| `js/app.js` | Page logic |
| `assets/` | Favicons and site icon |
| `demo/` | Sample client builds |

`index.html` is composed at runtime by `js/app.js`; the maintenance
tools that generate `css/style.css` and `js/app.js` are kept out of
this repository.

## Theme

Light/dark follows the OS preference; the toggle (sun/moon icon)
lets visitors override it per browser.
